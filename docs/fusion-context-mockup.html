03 / Methods & reproducibility Embedded readme

What this report does

Summarizes the existing rearrangement evidence, then places partner expression in processed T1 RNA and T0 protein contexts. Source units and timepoints remain separate.

Planned invocation

python -m fusion_context run \
  --manifest data/manifests/resolved-manifest.json \
  --config config/project.json \
  --out results/demo

This is the planned CLI interface. The mockup does not execute it.

Read and run

This file is self-contained and works offline. External IGV and source links require internet access. Use the evidence and partner buttons to switch views; hover, focus or tap marks for details.

Interpretation boundaries

  • No inference of longitudinal change from unmatched modalities.
  • No substitution of coding-gene protein for an antisense transcript.
  • No pooling of counts across reprocessed alignments.
