03 / Methods & reproducibility Embedded readme

What this report will do

Summarize one candidate's partner expression using processed T1 RNA and T0 protein data. Preserve existing annotations and source units. Compare contexts descriptively.

Planned invocation

python -m fusion_context run \
  --manifest results/preflight/resolved-manifest.json \
  --config config/project.json \
  --out results/demo

This is the planned CLI interface. The mockup does not execute it.

Read and run

This file is self-contained and works offline. External source and repository links require internet access. Use the partner buttons to switch views; hover, focus or tap marks for details.

Interpretation boundaries

  • No fusion calling or fusion-specific quantification.
  • No inference of longitudinal change from unmatched modalities.
  • No substitution of coding-gene protein for an antisense transcript.
  • No imputation of missing proteins or hidden mapping ambiguity.
